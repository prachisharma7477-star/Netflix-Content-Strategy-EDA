# Netflix Content Strategy: Exploratory Data Analysis
**EDA Project | Python · Pandas · Data Visualization**

## 🎬 Project Overview
An in-depth Exploratory Data Analysis (EDA) of the Netflix library to uncover content trends, audience preferences, and global expansion strategies.

## 🔍 Business Questions Answered
- How has the ratio of Movies vs. TV Shows changed over the last decade?
- Which countries are the top contributors to Netflix's original content?
- What are the most common ratings and genres on the platform?

## 🛠️ Analysis Process
1. **Data Cleaning:** Handled missing values in 'Director' and 'Cast' columns.
2. **Feature Engineering:** Extracted 'Year' and 'Month' from release dates.
3. **Visualization:** Created Heatmaps and Bar Charts to show content growth.

## 💡 Top Recommendations
- **Regional Focus:** Increase investment in content from Southeast Asia and Africa to capture emerging markets.
- **Retention:** Prioritize multi-season TV Shows over standalone movies to improve subscriber retention.
- **Timing:** Schedule major "Original" releases between October and December for maximum viewership.# Netflix-Content-Strategy-EDA
